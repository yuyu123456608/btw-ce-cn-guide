# 德爷生存 · BTW 中文图鉴站

Minecraft 1.6.4 · Better Than Wolves Community Edition **3.1.1** 的中文物品图鉴与合成速查。

非官方粉丝站。所有配方与材料名均来自对本模组 class 文件的反编译核对，不取自猜测，也不补写未经核实的配方。
未能在源码中定位产出方式的条目，一律不进入图鉴展示。

## 数据口径

| 项 | 数量 |
|---|---|
| 核心条目总数 | 198 |
| 已在图鉴展示 | 141 |
| 配方已核实（3×3 合成） | 59 |
| 机器加工配方 | 120 行（63 条含加工方式） |
| 待补归档条目 | 57 |
| 物品图标 | 138 张（16×16，取自模组贴图） |

## 目录内容

- `index.html` — 站点页面（单文件，含样式与逻辑）
- `items.js` — 物品数据（`BTW_ITEMS` 141 条 / `BTW_ITEMS_ARCHIVE` 57 条）
- `guides.js` — 7 篇生存路线
- `icons/` — 物品图标
- `og.png` — 社交分享卡片（1200×630）

## 说明

站点使用 hash 路由（`#/item/xxx`），无需服务器端路由配置，可直接静态托管。
条目详情页共享同一张分享卡片，这是 hash 路由的固有行为。
